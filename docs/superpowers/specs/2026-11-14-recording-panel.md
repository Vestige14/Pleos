# 3단계 녹음 패널 설계

2026-11-14. 제품 일반 진입·실제 오프라인 발화·저장·복원 수락을 확인했고 최종 통합 검토 중이다. 이 문서 자체는 릴리즈 완료 선언이 아니다.

## 요구와 선택

사용자는 녹음을 필수 기능으로 유지하고, 내비가 계속 보이면 작은 창과 분할 패널 모두 허용했다. 일반 알림센터를 개발 명령으로 여는 방식은 정상 진입 완료로 수락하지 않았다.

권한 없는 UI 실험에서 작은 dialog Activity는 실제로 내비를 가렸다. 공개 `FLAG_ACTIVITY_LAUNCH_ADJACENT` 요청도 현재 이미지에서 내비가 패널을 덮고 새 내비 작업의 초기화가 지연됐다. 두 경로는 제품에 사용하지 않는다.

고정 화면 방향을 제거한 패널은 **일반 앱 목록으로 실행한 뒤 오른쪽 창 막대를 왼쪽으로 드래그**하면 내비와 나란히 표시됐다. 공식 콘솔 D·36km/h 상태에서도 양쪽 UI가 유지되고 패널 클릭이 전달됐다. 이 실험은 버튼 진입의 증거이며 실제 음성 저장 검증과 구분한다. 지도 타일·목적지 경로 안내까지 검증한 것은 아니다.

## 구현 계약

- 별도 `DrivingActivity`를 앱 목록의 **기억 저장소 · 녹음**으로 제공한다. 화면 방향을 고정하지 않고 크기 변경을 허용한다. 주행 허용 메타데이터는 이 음성 전용 화면에만 적용한다.
- 주차용 `MainActivity`의 편집 기능과 주행 제한은 유지한다. 녹음 패널에 원문·방문 목록·입력창·공유 기능을 넣지 않는다.
- 패널은 녹음 상태와 큰 시작·취소 버튼을 표시한다. 신뢰된 DRIVING에서만 시작하고, 실제 클릭 시 최신 상태를 다시 확인한다. 앱 실행·복원·화면 크기 변경·외부 Intent만으로 녹음을 시작하지 않는다.
- 실제 SDK의 Listening 상태에서만 녹음 중으로 표시한다. 준비·처리·저장 성공·실패를 구분한다.
- 기존 `AppUiBridge`, `VoiceMemoService`, 세션 제어기와 Room 저장을 재사용한다. 15초 캡처·20초 최종 결과 제한, 중복 방지, UNKNOWN 취소, 원문 불변 및 방문 미지정 저장 계약을 바꾸지 않는다.
- 권한 준비는 주차 중 기존 앱에서 한다. 패널의 주차 설정은 최신 PARKED를 재확인하고 기존 MainActivity의 별도 작업으로 이동한다. 주행·UNKNOWN에서 설정이나 편집 화면을 열지 않는다.
- 새 시스템 권한, overlay, Gleo, 미디어 버튼 선점, 내비 앱 자동 실행은 추가하지 않는다.

## 검증과 완료 경계

화면 테스트는 주행 시작, 중복 클릭, 취소, 주차·UNKNOWN 차단, 클릭 직전 상태 변경, 녹음 상태 구분, 일반 launcher 및 외부 Intent의 자동 시작 금지를 확인한다. 기존 JVM·Room·주차 화면 검사도 유지한다.

제품 APK에서는 일반 앱 목록→분할 조작→D 상태→사용자 직접 시작→오프라인 실제 발화→저장 완료→P 상태 원문 확인·재실행 복원을 검증해야 한다. 녹음 중 내비 유지와 종료 후 마이크 해제를 함께 확인한다. UI 실험이나 빌드 성공만으로 이 수락 조건을 대체하지 않는다.

실제 제품에서 일반 진입·D36·사용자 버튼·내비 유지·오프라인 원문 저장·주차 표시·재부팅 및 앱 재실행 보존을 확인했고 사용자가 원문 일치를 확인했다. 전체 기기 검사 43개와 task 독립 검토도 통과했다. 알림센터 자체의 진입 문제와 Gleo 시작은 별도 미해결 사항이며, 분할 패널을 정상 녹음 진입의 대안으로 사용한다. 3단계 결과 보고 뒤 중단하며, 4단계나 원격 게시를 자동으로 시작하지 않는다.
