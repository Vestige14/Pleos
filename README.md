# 기억 저장소 · Pleos

차량에서 남긴 방문·사진·음성 메모를 하루의 기록으로 정리하고, 사용자가 고른 내용만 공유하는 Pleos 앱입니다.

## 현재 상태

**3단계 오프라인 메모 기능을 개발 중**입니다. 첫 릴리즈 목표는 메모·사진·공유와 OpenAI 방문 연결까지입니다. 구현된 기능, 검증 상태와 다음 작업은 [인수인계](docs/HANDOFF.md)에서 확인하세요. 개발 중인 로컬 브랜치와 GitHub main의 소스는 다를 수 있습니다.

## 시작하기

에이전트에게 아래와 같이 요청하면 됩니다.

> https://github.com/chowonbhin/Pleos.git 를 clone하고, AGENTS.md와 docs의 모든 MD·PDF를 읽은 뒤 현재 소스에 맞는 개발 환경을 확인하고 앱을 빌드·실행해줘. 사용자의 조작이 필요한 부분은 알려줘.

에이전트는 [AGENTS.md](AGENTS.md)의 규칙을 읽고, [환경 설정·실행 안내](docs/SETUP.md)에 따라 준비합니다. 이미 설치된 도구와 기존 작업은 보존합니다. Pleos 이미지 설치·라이선스·로그인·마이크 권한은 환경에 따라 사용자 조작이 필요할 수 있습니다.

직접 작업하는 개발자도 같은 문서를 따라 시작할 수 있습니다. clone 자체가 설치나 실행을 자동으로 수행하는 것은 아닙니다.

## 변경 사항 올리기

**매 push 전에 인수인계 문서에 본인이 개발한 내용·검증 결과·다음에 개발할 기능을 갱신합니다.** 최신 main pull → 로컬 merge → 병합 결과 로컬 검증 → 인수인계·비밀정보 점검 → 승인된 origin push 순서로 진행합니다. 상세 규칙은 [AGENTS.md](AGENTS.md)를 따릅니다.
