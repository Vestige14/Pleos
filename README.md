# 기억 저장소 · Pleos

방문·사진·음성 메모를 하루의 기록으로 정리하고, 사용자가 고른 내용만 공유하는 Pleos 앱입니다.

## 현재 상태

**v0.1.0은 로컬 실행용 소스 릴리즈입니다.** `release/v0.1.0` 브랜치와 `v0.1.0` 태그를 기준으로 환경을 준비해 사용합니다. APK·API 키·서명키·사용자 녹음은 제공하지 않으며, 공개 서버를 운영하지 않습니다. [릴리즈 안내](docs/releases/v0.1.0.md)에 준비 사항과 알려진 제한을 정리했습니다.

원본 음성·STT 저장, 사진 연결, 선택한 내용의 공유, 로컬 백엔드를 통한 AI 기억 연결과 사용자 확인·수정·해제를 구현했습니다. 여러 문장을 말할 때 첫 구절만 인식되던 문제를 수정했고, 실제 녹음 3개의 끝 문장과 원음 보존을 확인했습니다.

AI가 모호한 후보를 REVIEW로 보류하는 경우와 실제 내비 도착 미확인, 알림센터 진입 및 UI 간헐 문제는 남아 있습니다. 모든 기기·시나리오 통과를 뜻하지 않으며, 상세 근거는 [인수인계](docs/HANDOFF.md)를 확인하세요.

## 시작하기

에이전트에게 아래와 같이 요청할 수 있습니다.

> 이 저장소의 AGENTS.md와 docs의 모든 MD·PDF를 읽고, 현재 소스에 맞는 개발 환경을 확인한 뒤 앱을 빌드·실행해줘. 필요한 사용자 조작을 안내하고 TESTING.md의 절차로 검증해줘.

처음 저장소를 받는 방법과 환경 준비는 [SETUP.md](docs/SETUP.md), 실제 시험은 [TESTING.md](docs/TESTING.md)를 따릅니다. 기존 도구·설정·AVD·데이터를 보존하고 실제 발화 시점은 사용자와 맞춥니다. 저장소를 받는 것만으로 설치나 실행이 자동 수행되지는 않습니다.

## 변경 사항 올리기

매 push 전에 인수인계에 개발 내용·검증한 소스와 한계·다음 작업을 갱신합니다. **main pull → 로컬 merge → 병합 결과 검증 → 인수인계·비밀정보 점검 → 승인된 origin push** 순서입니다. 각 단계 완료 후 보고하고 중단하며, 다음 단계는 사용자 지시 후 시작합니다.
